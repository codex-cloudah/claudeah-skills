# 公开Skill库

仓库名称：`claudeah-skills`  
计划可见性：**public**  
用途：保存已标准化、可公开的 Skill 及其说明、资源与验证记录。已迁入内容视觉化 Skill。

## 目录

- `skills/`
- `templates/`

## 使用

新增资料后按 [分类与标签规范](TAGS.md) 填写信息；Markdown 使用相对路径引用附件，方便手机和电脑阅读。
`inbox`（如有）存待整理资料；`templates` 存资料模板。
当前仅为初始化结构，尚未收录历史资料，也尚未接通 AI 检索与修改服务。

此仓库用于公开分享。上传前删除私人资料与凭据；公开可见不等于已授予开源许可，许可证另行确定。
